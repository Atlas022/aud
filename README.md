# Aud/

Outil pédagogique d'analyse de code, créé par les TSSR de Montpellier pour acquérir les rudiments du code.

- Gratuit, sans compte, sans serveur : un seul fichier `index.html`.
- La progression est enregistrée uniquement dans le navigateur de l'utilisateur (`localStorage`, clé `aud-save`) ; rien n'est envoyé.
- Seule connexion initiée par Aud/ : le téléchargement de jsPDF (cdnjs) quand on demande un PDF, après confirmation.
- Langages : Bash, Shell, PHP, HTML, CSS, JavaScript, Python, Java, C/C++, Rust.

Le code source est ce fichier : ouvre `index.html` pour le lire.
